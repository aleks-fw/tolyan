# Толян: аренда грузовиков и доставка стройматериалов

Сайт на чистых HTML, CSS и JavaScript, без фреймворков и без установки зависимостей.

## Как открыть

- Двойным кликом по `index.html` (сайт) и `admin.html` (админ-панель).
- Или через локальный сервер из папки проекта: `python -m http.server 8765`, затем http://127.0.0.1:8765/.

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html`, `css/site.css`, `js/site.js`, `js/orders.js` | Публичный сайт: каталог, бронь, форма доставки, окно «Заказ оформлен» |
| `admin.html`, `css/admin.css`, `js/admin*.js` | Админ-панель: заказы, материалы, грузовики, настройки |
| `js/store.js` | Слой данных (сейчас localStorage). Единый интерфейс для сайта и админки |
| `js/seed.js` | Стартовые материалы, грузовики и настройки (демонстрационные цены) |
| `js/lib/*.js` | Чистые функции: расчёт, проверка полей, текст заказа и ссылки Telegram |
| `js/config.js` | Пароль демо-режима и (на будущее) ключи Supabase |
| `assets/img/` | Фото с Pexels и SVG-заглушки, источники в `CREDITS.md` |
| `tests/` | Юнит-тесты на Node |
| `docs/plan.md` | Исходный план проекта |

## Админ-панель

Вход: пароль из `js/config.js` (поле `demoPassword`, по умолчанию `tolyan`). Поменяйте его перед публикацией.

Разделы: заказы и брони (статусы, поиск, копирование текста), материалы, грузовики, настройки (название, контакты,
тексты главной, ник Telegram, резервная копия).

## Заказы и Telegram

1. Клиент оформляет заказ, он сохраняется в хранилище со статусом «Новый».
2. Показывается окно «Заказ оформлен» с готовым текстом и кнопками «Скопировать заказ», «Открыть Telegram владельца»,
   «Отправить заказ в Telegram».
3. Ник владельца меняется в админке (Настройки, блок Telegram).

Ссылка «Отправить» открывает `https://t.me/<ник>?text=...`. Не все клиенты Telegram подставляют текст сами, поэтому
текст при нажатии ещё и копируется в буфер: его можно вставить в чат вручную.

## Подсказки адреса

При вводе адреса (форма доставки и бронь) показываются варианты из OpenStreetMap через публичный сервис Photon
(photon.komoot.io, без ключа). Введённый текст отправляется на этот сервис. Отключается в админке: Настройки, блок
«Подсказки адреса». Если сервис недоступен, поле работает как обычное. Для большой нагрузки стоит перейти на платный
сервис (например, Яндекс или DaData) или поднять свой Photon.

## Важное ограничение демо-режима

Данные лежат в `localStorage` браузера, в котором открыт сайт. Заказ, сделанный клиентом на своём телефоне, **не
появится** в админке на другом устройстве. Для реальной работы нужна общая база (раздел ниже). До этого момента:
- регулярно скачивайте резервную копию (Настройки, Резервная копия);
- не очищайте данные сайта в браузере.

## Подключение общей базы (Supabase), когда понадобится

Сайт и админка обращаются к данным только через `Tolyan.store` (`js/store.js`). Чтобы подключить базу:

1. Создать проект Supabase и таблицы `materials`, `trucks`, `orders`, `settings` (поля описаны в `docs/plan.md`).
2. Закрыть таблицу `orders` для чтения анонимным пользователям, создание заказа сделать функцией на сервере, которая
   пересчитывает сумму по ценам из базы, как это уже делает `buildOrder` в `js/store.js`.
3. Написать `js/store-supabase.js` с тем же набором методов (`listMaterials`, `createOrder`, `login` и т.д.) и
   `mode = 'supabase'`, подключить его вместо `store.js` при заполненных `supabaseUrl` и `supabaseAnonKey` в
   `js/config.js`. Вход в админку уже готов к режиму почта + пароль.
4. Фото загружать в Storage вместо data URL.

## Бот Telegram (отправка без действий клиента)

После сохранения заказа вызывается `store.hooks.onOrderCreated(order)` (сейчас пустой). К нему можно подключить
серверную отправку: бот Telegram Bot API через собственный сервер или Database Webhook и Edge Function в Supabase.
Прямо из браузера токен бота хранить нельзя.

## Тесты

```
node --test "tests/*.test.js"
```

Покрывают расчёт стоимости, проверку полей, текст заказа, ссылки Telegram и слой данных (создание заказа, остатки,
статусы, экспорт и импорт, вход).
